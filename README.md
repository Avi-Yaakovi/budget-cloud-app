# תקציב הבית

אפליקציית ניהול תקציב משק בית, עברית RTL.

## תכולה
- `index.html` — הממשק כולו (HTML + CSS + JS, ללא תלויות בנייה)
- `api/data.js` — קריאה/כתיבה של הנתונים ל-Redis
- `api/chat.js` — פרוקסי לשאלות חופשיות על התקציב

## משתני סביבה נדרשים
| משתנה | תפקיד |
|---|---|
| `REDIS_URL` | חיבור למסד הנתונים (חובה) |
| `APP_CODE` | קוד גישה לאתר. אם לא מוגדר — האתר פתוח |
| `ANTHROPIC_API_KEY` | מפעיל את הצ'אט. אם לא מוגדר — הצ'אט מציג הנחיה |

## תכונות
ייבוא קבצי אשראי (כאל, MAX, ישראכרט) עם זיהוי חברה, כרטיס ומחזיק · מניעת כפילויות · תנועות קבועות עם החלה על חודשים קודמים · מגמה חודשית · תקציב לפי קטגוריה · פילוח לפי כרטיס · חיפוש ועריכת תנועות · גיבוי ושחזור · קוד גישה
